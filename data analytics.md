# Data Analytics

Data analytics is the process of collecting, cleaning, transforming, and interpreting data to discover patterns, trends, and insights that support better decision-making.

## Key areas
- Descriptive analytics: what happened
- Diagnostic analytics: why it happened
- Predictive analytics: what is likely to happen
- Prescriptive analytics: what action should be taken

## Common tools
- Python
- R
- SQL
- Excel
- Power BI
- Tableau

## Example workflow
1. Define the problem
2. Collect relevant data
3. Clean and prepare the data
4. Analyze and model the data
5. Communicate results
